# Rlaunch

macOS 26 起系统移除了 Launchpad，Rlaunch 是其轻量优雅的 AppKit 原生平替：无边框圆角窗口、动态模糊背景、网格吸附分页、多维文件夹归类、批量多选中转站与全局快捷唤起，兼顾流畅交互与低资源占用。

## 核心功能

### 1. 窗口与网格
- **无边框质感窗口**：圆角与柔和阴影，窗口化模式下长按顶栏空白处可自由拖动；支持一键全屏/退出全屏。
- **吸附分页网格**：应用与文件夹按网格对齐，横向滑动松手自动吸附整页；到首页/尾页后继续拖动带**橡皮筋阻尼**，松手平滑弹回，不再硬邦邦地停住；全屏时图标、文字与间距自适应缩放铺满。
- **独立页面管理**：支持页面空间留白，跨页移走后不破坏原页面布局，空页面自动智能回收。
- **顶栏集成**：原生手感自绘三色按钮（关闭/最小化/全屏）、实时模糊搜索框、页码点击翻页、重新扫描与设置入口。
- **随手即搜**：窗口唤出后无需先点搜索框，直接敲键盘即可开始搜索；`↩` 打开焦点条目（或搜索结果第一项），`⌘F` 聚焦搜索框，`←/→` 翻页，`Esc` 逐层退出（关闭文件夹弹窗 → 退出多选 → 退出全屏）。
- **键盘导航**：`↑/↓` 建立并移动键盘焦点（蓝色高亮环），横向到边界自动翻页，全程无需鼠标即可启动应用；已有焦点时 `←/→` 在网格内移动。
- **运行中指示**：正在运行的应用在图标下方显示小圆点；右键可「退出应用」「在访达中显示」。
- **隐藏应用**：右键应用选择「从启动台隐藏」即可把它移出启动台（同时从文件夹中移出），在「设置 → 应用扫描 → 已隐藏的应用」中一键恢复。
- **空状态指引**：完全没扫到应用时给出提示与「重新扫描」入口，搜索无结果时提示更换关键词，不会留下一片空白。
- **失效应用兜底**：点击已被移动/删除的应用会给出提示并自动重新扫描，右键菜单等操作全部改为窗口内浮层，全屏下也不会被遮挡或卡住。
- **位置记忆**：窗口大小与屏幕位置自动记忆，下次启动回到上次的位置；首次启动自动居中，显示器变更导致位置失效时也会自动居中。

### 2. 文件夹系统
- **动态预览图标**：文件夹卡片直观显示内部应用缩略图；内部应用超出槽位时，末尾以多层叠放样式呈现并标注重叠数量。
- **自定义网格尺寸**：右键文件夹可自由调整尺寸（1×1、2×2、2×3 等），占用多格并自适应网格流式排布。
- **轻量展开弹窗**：点击展开居中卡片（首屏置顶最上层应用），卡片尺寸、列数与图标大小随界面尺寸动态伸缩（全屏时自动放大、应用少时自动收紧高度），并完整适配浅色 / 暗色主题；支持就地重命名标题、快捷解散文件夹、单个应用右键移出。
- **解散与释放**：解散文件夹时，其内部应用按序释放回当前页及后续页，自动顺延排布。
- **防嵌套与拖入动效**：严格禁止文件夹嵌套；将应用拖至文件夹上方时触发弹性微缩放与光晕高亮，松手即入。

### 3. 多选、中转站与拖拽重排
- **长按多选**：长按任意 App 或文件夹进入多选模式（右上角显示选择徽章），上限 10 项（超额 Toast 提醒并置灰不可选条目）。
- **右侧悬浮中转站**：
  - 选中条目自动入站，悬停可快捷单个移除；
  - 选中 ≥2 个 App 时可一键「建文件夹」；
  - 支持一键「放本页」或打开文件夹后「放文件夹」。
- **批量拖拽排序**：长按多选后拖动，严格**按照选中的先后时间顺序**一次性插入目标位置，附带 Retina 2x 高清拖拽预览图与计数胶囊角标。
- **互斥防护**：文件夹与其内部包含的应用自动互斥选中，避免逻辑冲突。

### 4. 语言与本地化
- **简体中文 / English**：默认简体中文，设置 →「通用」→「语言」中切换，**切换后界面立即生效、无需重启**。
- 文案集中在 `Sources/RlaunchCore/L10n.swift`，以简体中文原文为键；缺失译文时自动回退中文（不会出现空白或 key 泄漏），并有一条自测守护「无重复键」。

### 5. 外观与主题
- **深浅模式自适应**：全面适配浅色（Light）、深黑（Dark）与跟随系统；文件夹卡片与展开弹窗采用高通透高光与高饱和背景，避免界面穿透交叠。
- **背景与毛玻璃**：支持自定义背景图片、透明度（15%~100%）与高斯模糊（0~60）。macOS 26 (Tahoe) 及以上使用系统原生 **Liquid Glass**（`NSGlassEffectView`），更早系统自动回退到 `NSVisualEffectView`；设置 →「外观」中会显示当前实际使用的渲染方式。
  如需强制回退（排查显示异常时），可用 `RLAUNCH_GLASS=legacy open Rlaunch.app` 启动。

## 唤起说明

- **全局快捷键**：设置 →「快捷键」→「录制快捷键…」，采用系统 Carbon 热键接口，无需辅助功能权限。
- **四指 / 五指捏合**：触控板四指/五指间距向内捏合收缩触发：不在前台时唤起并全屏，已在前台时收起。需要「辅助功能权限」（设置中提供快捷授权检测与跳转）。
- **菜单栏图标**：
  - **左键点击**：直接唤出 / 收起「小屏窗口化」界面（不弹菜单），已在窗口化前台时点击即收起，全屏状态下点击会先退出全屏再以窗口化呈现；
  - **右键（或 ⌃ + 左键）**：弹出「显示 / 隐藏、设置…、退出 Rlaunch」菜单。
- **启动后自动收起**：点击运行 App 后自动隐藏窗口（可通过配置项 `hideOnLaunch` 开启/关闭）。

## 关于

- **项目主页**：<https://github.com/ccdyy/Rlaunch>（设置 →「通用」→「关于」中可直接点击打开或复制地址）。
- **版本号**：由构建时的 git tag 自动写入 `Info.plist` 的 `CFBundleShortVersionString`，Release CI 用发布 tag 覆盖，
  因此本地构建与发布包都带有准确的 tag 版本（可在「访达 → 显示简介」中查看）。
- **配置维护**：设置 →「通用」→ 提供「打开配置目录」「导出…」「导入…」，以及「恢复默认设置」（仅重置设置项，保留文件夹与桌面布局）与「重置桌面布局」（仅清空文件夹与页面编排）。

## 构建与运行

```bash
# Release 构建（输出 Rlaunch.app）
./build.sh

# Debug 构建
./build.sh debug

# 运行自动化测试套件（无 XCTest 依赖，覆盖搜索、配置、文件夹解散/排序/去重等）
swift run --package-path . --disable-sandbox RlaunchSelfTest
```

启动运行：`open Rlaunch.app`。应用为菜单栏驻留型（LSUIElement，无 Dock 图标）。

## 配置文件

配置文件路径：`~/Library/Application Support/Rlaunch/config.json`
包含了扫描目录列表、扫描递归层级、主题、背景样式、网格布局行列数、窗口尺寸与位置（`windowWidth`/`windowHeight`/`windowX`/`windowY`）、快捷键键值、捏合灵敏度开关、自定义页面排序（`pageOrders`）与文件夹信息。

## 项目结构

```
Sources/RlaunchCore/       核心数据层：模型与配置持久化、App 扫描器、图标缓存、模糊搜索、本地化文案，
                           以及可单测的网格装箱（GridPacker）与分页/文件夹编排（PageComposer）
Sources/Rlaunch/           AppKit 交互层：主窗口控制器、顶栏、吸附滚动容器、网格页面、条目组件、文件夹弹窗、中转站、窗口内浮层
Sources/RlaunchSelfTest/   单元自测：搜索、配置往返迁移、网格装箱与分页编排、扫描去重等断言
```

> 网格布局与分页容量共用 `RlaunchCore/GridPacker` 的同一套装箱算法，
> 保证「分页认为放得下」的条目在界面上一定有位置，不会因文件夹占多格而被静默隐藏。
